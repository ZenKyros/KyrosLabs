## Jacobian

The Jacobian contains the partial derivatives of a **vector-valued function**.

If:

$$
f(x,y)=
\begin{bmatrix}
f_1(x,y)\\
f_2(x,y)
\end{bmatrix}
$$

then:

$$\boxed{ J = \begin{bmatrix} \dfrac{\partial f_1}{\partial x} & \dfrac{\partial f_1}{\partial y} \\[1em] \dfrac{\partial f_2}{\partial x} & \dfrac{\partial f_2}{\partial y} \end{bmatrix} }$$

### AI uses

Jacobians appear in:

* Neural networks
* Backpropagation
* Coordinate transformations
* Optimization

## Hessian

The Hessian contains the **second-order partial derivatives**:

$$\boxed{ H_{ij} = \dfrac{\partial^2 f}{\partial x_i \partial x_j} }$$

where:
* $H_{ij}$ is the entry of the Hessian matrix at the $i$-th row and $j$-th column.
* $f$ is the multivariable scalar function being evaluated.
* $x_i$ and $x_j$ are the independent input variables representing the coordinate axes.
* $\dfrac{\partial^2 f}{\partial x_i \partial x_j}$ represents the rate at which the partial derivative with respect to $x_i$ changes along the direction of $x_j$.

It describes the **curvature** of a function.

Used in advanced optimization methods such as Newton's method.


## Chain Rule

The chain rule tells us how to differentiate **composed functions**.

If:

$$y = f(g(x))$$

then:

$$\boxed{ \dfrac{dy}{dx} = \dfrac{df}{dg} \cdot \dfrac{dg}{dx} }$$

where:
* $\dfrac{dy}{dx}$ is the **total derivative** of the output $y$ with respect to the original input $x$.
* $\dfrac{df}{dg}$ is the derivative of the **outer function** $f$ with respect to its immediate input (the inner function $g$).
* $\dfrac{dg}{dx}$ is the derivative of the **inner function** $g$ with respect to the independent variable $x$.
* $g(x)$ acts as an **intermediate variable** linking the input directly to the final layer.


### Why it matters in AI

Neural networks are complex compositions of functions:

$$x \rightarrow f_1 \rightarrow f_2 \rightarrow f_3 \rightarrow L$$

The chain rule allows us to calculate the sensitivity of the final loss relative to any given weight:

$$\boxed{ \dfrac{\partial L}{\partial w} }$$

for parameters deep inside the network.

where:
* $\partial$ represents the partial derivative symbol.
* $L$ is the **Loss function** output (the scalar value measuring the model's total prediction error).
* $w$ is an individual **weight parameter** (a tunable connection strength deep inside a hidden layer).
* $\dfrac{\partial L}{\partial w}$ is the **gradient of the loss with respect to that weight** (tells the optimization algorithm exactly how much the error will change if you adjust that specific weight).

**Backpropagation is essentially the chain rule applied efficiently through a neural network.**

## Computational Graphs

A computational graph represents a calculation as a sequence of distinct mathematical operations.

Example equations:

$$z = xy$$

$$L = z^2$$

Graph layout flow:

$$x, y \rightarrow z=xy \rightarrow L=z^2$$

During the forward pass, we calculate the numeric outputs of each node.

During the backward pass, we calculate the incoming gradients.

For example, the local gradient is:

$$\dfrac{\partial L}{\partial z} = 2z$$

And using the chain rule, the downstream gradient is:

$$\boxed{ \dfrac{\partial L}{\partial x} = \dfrac{\partial L}{\partial z} \cdot \dfrac{\partial z}{\partial x} }$$

This is the foundation of **backpropagation**.

where:
* $L$ is the final output node value (typically representing the **Loss**).
* $z$ is an **intermediate node variable** generated by multiplying the inputs ($xy$).
* $x$ and $y$ are the **independent input variables** or parameters feeding into the graph.
* $\dfrac{\partial L}{\partial z}$ is the **upstream gradient** flowing backward from the loss into node $z$.
* $\dfrac{\partial z}{\partial x}$ is the **local gradient** of node $z$ with respect to its input $x$ (which simplifies to equal $y$).
* $\dfrac{\partial L}{\partial x}$ is the **total accumulated downstream gradient** passed back to parameter $x$.


## Optimization

Optimization means finding parameters that minimize a loss function.

$$\boxed{ \theta^* = \operatorname*{argmin}_{\theta} L(\theta) }$$


### Gradient Descent

Basic update rule:

$$\boxed{ \boldsymbol{\theta}_{\text{new}} = \boldsymbol{\theta}_{\text{old}} - \eta \nabla L(\boldsymbol{\theta}) }$$

where:
* $\boldsymbol{\theta}$ (Theta) represents the **model parameters** (the vector of weights and biases being optimized).
* $\boldsymbol{\theta}^*$ is the **optimal parameter vector** that successfully achieves the lowest possible error value.
* $\boldsymbol{\theta}_{\text{new}}$ is the updated parameter vector calculated for the next step of training.
* $\boldsymbol{\theta}_{\text{old}}$ is the current parameter vector before applying the gradient step.
* $L(\boldsymbol{\theta})$ is the **Loss function** evaluating the performance of the current parameters.
* $\nabla L(\boldsymbol{\theta})$ (Nabla L) is the **gradient vector** containing all first-order partial derivatives of the loss function, pointing in the direction of the steepest ascent.
* $\eta$ (Eta) is the **learning rate**, a scalar hyperparameter that controls the step size taken down the gradient slope.
* $-$ (the subtraction sign) forces the step to move in the direction opposite to the gradient to achieve minimization (**steepest descent**).

### Intuition

1. Calculate loss.
2. Calculate gradient.
3. Move parameters opposite to the gradient.
4. Repeat.

This is the basic mechanism behind training many ML models.



## Automatic Differentiation

Automatic differentiation (Autodiff) automatically calculates derivatives by applying the chain rule to computational operations.

It is **not the same as numerical differentiation** and does not require manually deriving every gradient.

Modern deep-learning frameworks use autodiff.

Example in PyTorch:

```python
import torch

x = torch.tensor(3.0, requires_grad=True)

y = x**2

y.backward()

print(x.grad)
```

Output:

```text
tensor(6.)
```

because:

$$
\frac{dy}{dx}=2x=6
$$

### Key idea

**Calculus → Derivatives → Gradients → Chain Rule → Backpropagation → Optimization → Neural-network training**

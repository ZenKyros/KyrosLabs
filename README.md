# KeasAI

Learn AI with KeasAI.

KeasAI is a structured learning journey focused on building a strong foundation in **Mathematics, Machine Learning, and Deep Learning** — from the fundamentals to advanced AI concepts.

## Goal

The goal of KeasAI is to help you **understand AI from first principles**, build the mathematical intuition behind it, and gradually progress toward implementing and mastering modern Machine Learning and Deep Learning systems.

> **Learn the math → Understand the concepts → Build the models → Master AI**
